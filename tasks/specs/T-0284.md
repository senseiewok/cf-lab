## 1. Operational Security & Architecture Stewardship Scope

Implements `tasks/prune_stale_worktrees.py` to automate scheduled cleanup of fully merged, clean worktrees across all sibling repositories (`cf-lab`, `cf-research`, `cf-skills`, `.ai`). Builds directly on `tasks/harvest_sentinel_worktrees.py` with rigorous data-loss prevention invariants:
1. Strict prerequisite safety check: 0 uncommitted changes, 0 untracked files, 0 unpushed commits, and verified PR merge status (`MERGED` via GitHub API or git ancestor verification on `origin/main`).
2. Requires explicit `--yes` flag to execute live deletions; defaults to comprehensive dry-run preview emitting JSON summary.
3. Automatically prunes associated local branch references and cleans git worktree administrative metadata (`git worktree prune`).
4. Logs structured telemetry into `.loop-logs/worktree-prune.json` with sanitized paths and timestamps.

## 2. Primary Source Grounding

1. **tasks/harvest_sentinel_worktrees.py**: Core harvest candidate inspection, dirty checks, and merged PR mapping.
2. **.claude/skills/workspace-siblings/scripts/worktrees.py**: Worktree lifecycle management and directory structure.
3. **AGENTS.md**: Automated worktree hygiene and multi-repo isolation contract.
