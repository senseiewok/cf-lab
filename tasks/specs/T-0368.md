## 1. Curative Mission & Architecture Stewardship Scope

Implements `tasks/check_git_submodules.py` to audit git submodules, nested git directories, and `.gitmodules` configurations across all workspace repositories (cf-lab, cf-research, cf-skills, .ai):
1. **Submodule Architecture Invariants (CWE-829 / CWE-20)**: Verifies that no rogue or unreviewed git submodules exist across the multi-repo workspace, enforcing the lab's deliberate sibling repository design pattern (`cf-lab.code-workspace`) over brittle nested submodule structures.
2. **URL & Transport Security**: If submodules are declared in future tooling, verifies that URLs enforce HTTPS/SSH cryptographic transport and point exclusively to authorized GitHub organizations, strictly prohibiting unencrypted `http://` or `git://` transports (CVE-2018-11235 mitigation).
3. **Submodule Hook & Path Safety**: Prohibits path traversal sequences (`../`) or nested `.git/` hooks inside submodule path specifications.
4. **Deterministic Testing**: Includes comprehensive unit tests in `tasks/test_check_git_submodules.py` and registers check rows in `check-all.ps1`.

## 2. Primary Source Grounding

- CVE-2018-11235: Arbitrary code execution via git submodule .git/hooks directory traversal
- CWE-829: Inclusion of Functionality from Untrusted Control Sphere
- Workspace Standards: `.claude/skills/security-baseline/SKILL.md`, `.claude/skills/security-git/SKILL.md`
