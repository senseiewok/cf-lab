## 1. Curative Mission & Architecture Stewardship Scope

Implements `tasks/check_prompt_injection_invariants.py` to audit model prompt construction and template formatting across all workspace repositories (cf-lab, cf-research, cf-skills, .ai):
1. **Unescaped String Interpolation in Prompts**: Scans ASTs for raw unescaped variable injections (`f"..."`, `str.format()`, `%` formatting) in agent system prompts and user prompt packets that ingest untrusted external data (e.g. web search outputs, PMC abstracts, raw HTML).
2. **Structural Boundary Delimitation**: Enforces mandatory XML/tag boundary encapsulation (`<evidence>`, `<user_input>`, `<untrusted_content>`) around untrusted variables before inclusion in agent context windows.
3. **Canary & Injection Marker Probing**: Integrates with `.claude/skills/security-browsing/` probe definitions to verify that prompt injection tripwires and instruction boundary guards are properly enforced.
4. **Deterministic Testing**: Includes comprehensive unit tests in `tasks/test_check_prompt_injection_invariants.py` and registers check rows in `check-all.ps1`.
