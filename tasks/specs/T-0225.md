# T-0225: Automated Worktree Harvest & Duplicate-PR Preflight Guard

## 1. Overview & Curative Mission Focus (Infrastructure / Sentinel Governance)
Autonomous sentinels across the four workspace repositories (`cf-lab`, `cf-research`, `cf-skills`, `.ai`) execute in isolated git worktrees (`../.worktrees/<repo>/<topic>`). When an agent finishes a task or experiences a timeout/context compaction, unmerged commits often remain locally on disk without an open PR. If the next sentinel run picks the same task or lane without awareness of existing worktrees, it risks:
1. Re-implementing code from scratch (burning hundreds of thousands of tokens).
2. Opening conflicting duplicate pull requests against the same upstream files.
3. Overwriting clean, working biophysical models or web components.

This specification directs the implementation of an automated worktree harvest and preflight guard in `cf-lab` (`tasks/check_worktree_drift.py`) and its full integration into `tasks/pick_bold_task.py` and `scheduled-security-sentinel`.

## 2. Primary Evidence Grounding
- **Worktree Management Standard**: `.claude/skills/workspace-siblings/scripts/worktrees.py` governing worktree lifecycle across sibling repositories.
- **Task Picker Architecture**: `tasks/pick_bold_task.py` handling lane capacity, PR repair detection, and bold bundle construction.
- **Governance Record**: `tasks/BOARD.md` and `tasks/board.json` tracking multi-repo task coordination and branch isolation invariants.

## 3. Architecture & Functional Requirements
- **Directory Traversal**:
  - Automatically resolves workspace `.worktrees` directory across native checkouts and active worktree paths.
  - Recursively inspects every subdirectory (`.worktrees/*/*`) containing a valid `.git` reference.
- **Git Metadata Extraction**:
  - Extracts current branch (`git rev-parse --abbrev-ref HEAD`).
  - Checks for uncommitted changes (`git status --porcelain`).
  - Identifies unmerged commits ahead of upstream main (`git log origin/main..HEAD --oneline` or `git log main..HEAD --oneline`).
  - Parses referenced task IDs (`T-XXXX`) from branch names, worktree topics, and commit headers.
  - Determines lane affinity (`security`, `research`, `showcase`).
- **Picker Integration**:
  - `pick_bold_task.py` imports `scan_existing_worktrees` from `tasks/check_worktree_drift.py`.
  - When outputting `.loop-logs/bold-bundle-<lane>.json`, the payload includes `"existing_worktrees": [...]` listing matching unmerged worktree branches so the sentinel resumes/harvests existing commits.

## 4. Deliverables & Target Files
- In repository `cf-lab`:
  - `tasks/check_worktree_drift.py`: Core scanner and CLI utility supporting `--json`, `--lane`, `--task-ids`, and `--check`.
  - `tasks/test_check_worktree_drift.py`: Unit test suite verifying worktree detection, branch extraction, unmerged commit logging, and lane filtering.
  - `tasks/pick_bold_task.py`: Updated to include `existing_worktrees` in bundle JSON payloads.

## 5. Verification Command
Deterministic execution verifying zero external network calls:
```bash
python -m unittest tasks/test_check_worktree_drift.py
```
Or via script check:
```bash
python tasks/check_worktree_drift.py --json
```
