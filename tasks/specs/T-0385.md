## 1. Curative Mission & Architecture Stewardship Scope

Implements `tasks/check_subprocess_argument_safety.py` to audit `subprocess.Popen`, `subprocess.run`, `subprocess.call`, and `os.system` invocations across all workspace repositories (cf-lab, cf-research, cf-skills, .ai):
1. **Shell Injection Elimination (CWE-78 / CWE-88)**: Audits AST calls to prohibit `shell=True` anti-patterns when passing non-literal command strings; verifies that argument vectors are structured as discrete argument lists rather than raw string concatenation.
2. **Environment Variable Sanitization (CWE-522)**: Verifies that custom `env` dictionaries passed to subprocess calls explicitly sanitize secrets and do not inherit unconstrained sensitive process memory.
3. **Executable Path Canonicalization**: Audits executable names to ensure commands resolve through absolute paths or trusted system executables without relative path search ambiguity.
4. **Deterministic Testing**: Includes comprehensive unit tests in `tasks/test_check_subprocess_argument_safety.py` and registers check rows in `check-all.ps1`.
