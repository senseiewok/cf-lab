# Task Spec: T-0295 — Automated Multi-Repo Worktree Lock & Concurrent Sentinel Collision Guard (tasks/check_sentinel_concurrency_guard.py)

- **ID**: `T-0295`
- **Repository**: `cf-lab`

- **Priority**: `P1`
- **Review Tier**: `elevated`

## 1. Curative Mission & Architecture Scope

Implements `tasks/check_sentinel_concurrency_guard.py` and unit tests in `tasks/test_check_sentinel_concurrency_guard.py` to prevent race conditions and uncoordinated concurrent executions among scheduled multi-agent sentinels (`daily-security-sentinel`, `daily-research-sentinel`, `daily-site-showcase-sentinel`). Validates active lock file lifecycles (`.loop-logs/*.lock`), timestamp expiration against configured `lock_timeout_minutes` from `tasks/sentinels.json`, atomic PID ownership verification, and detection of overlapping dirty git worktrees across `cf-lab`, `cf-research`, `cf-skills`, and `.ai`.

## 2. Primary Source Grounding

1. `tasks/sentinels.json` (sentinel scheduling, cadence, watch paths, and lock timeout definitions).
2. `tasks/run-sentinel.ps1` (sentinel lock acquisition, execution wrapper, and release flow).
3. `tasks/prune_stale_worktrees.py` (stale worktree discovery and isolation invariants).
4. OWASP Top 10:2025 A01 (Broken Access Control) / CWE-362 (Concurrent Execution using Shared Resource with Improper Synchronization / Race Condition).
