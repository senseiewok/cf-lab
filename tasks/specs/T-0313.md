## 1. Curative Mission & Architecture Stewardship Scope

Implements `tasks/check_git_hooks_invariants.py` to audit git hook configurations, pre-commit wrappers, and setup scripts across all workspace repositories:
1. **Hook Directory Containment**: Asserts that git hooks (e.g. `.git/hooks/pre-commit`, `.githooks/`) do not execute unvetted external binaries or download untracked network payloads.
2. **Interpreter Portability**: Verifies all hook scripts invoke portable interpreters (`python3`, `pwsh -NoProfile`, `sh`) with explicit failure propagation (`set -e` or `$ErrorActionPreference = 'Stop'`).
3. **Canary & Secret Pre-Commit Integration**: Asserts that `check-staged.ps1` or equivalent privacy scanners are wired into pre-commit workflows to halt accidental secret commits before index mutation.
4. **Deterministic Testing**: Includes unit test suite in `tasks/test_check_git_hooks_invariants.py` and registers check rows in `check-all.ps1`.
