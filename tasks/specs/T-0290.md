## 1. Security Architecture & Release Integrity Scope

Implements `tasks/check_git_release_integrity.py` to audit git release tags, semantic versioning parity, and release packaging manifests across all workspace repositories (`cf-lab`, `cf-research`, `cf-skills`, `.ai`):
1. Verifies that every repository release tag matches `vX.Y.Z` semantic versioning rules and strictly aligns with `VERSION` files per `.claude/skills/lab-versioning/SKILL.md`.
2. Validates that release tags reference reachable commits on `origin/main` with complete commit provenance and zero detached HEAD anomalies.
3. Audits git release payload manifests and tarball archive staging to guarantee zero leakage of secret files (`.env`, `.env.*`), untracked machine memory (`../cf-lab-files/`), local runtime loops (`.loop-logs/`), or worktree state (`.worktrees/`).
4. Emits structured diagnostic audit reports to `.loop-logs/git-release-audit.json`.

## 2. Primary Source Grounding

1. **Workspace Versioning Policy**: `.claude/skills/lab-versioning/SKILL.md` and `cf-lab/VERSION`.
2. **Git Security & Secret Prevention**: `.claude/skills/security-git/SKILL.md` and `.claude/skills/security-baseline/SKILL.md`.
3. **OpenSSF Scorecard / Supply Chain Integrity**: SLSA Level 1/2 provenance and secure release tag hygiene.
