## 1. Curative Mission & Architecture Stewardship Scope

Implements `tasks/check_env_sanitization_invariants.py` to audit environment variable propagation, child process execution wrappers, and log formatting across all workspace repositories:
1. **Subprocess Environment Isolation**: Verifies that automated scripts and test harnesses invoking `subprocess.run`, `subprocess.Popen`, or PowerShell execution blocks do not blindly pass raw parent environment variables (`env=os.environ`) when executing external binaries or unvetted helper scripts.
2. **Secret Token Redaction**: Asserts that sensitive token names (`GH_TOKEN`, `GITHUB_TOKEN`, `PAT`, `ANTHROPIC_API_KEY`, `GEMINI_API_KEY`, `OPENAI_API_KEY`) are scrubbed from stderr, stdout logging sinks, and error diagnostic dumps.
3. **Canary Pattern Monitoring**: Verifies integration with `privacy-patterns.txt` and tests that mocked secret exposures trigger deterministic process termination.
4. **Deterministic Testing**: Includes unit test suite in `tasks/test_check_env_sanitization_invariants.py` and registers check rows in `check-all.ps1`.
