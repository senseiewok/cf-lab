## 1. Curative Mission & Architecture Stewardship Scope

Implements `tasks/check_git_tag_signatures.py` to audit git release tags and ref annotations across all workspace repositories (cf-lab, cf-research, cf-skills, .ai):
1. **Cryptographic Tag Integrity (CWE-347)**: Audits release tags to ensure they are annotated and cryptographically verified (GPG or SSH signing), prohibiting floating lightweight tags for released lab artifacts.
2. **Semver Release Taxonomy**: Enforces semantic versioning compliance (`v[0-9]+\.[0-9]+\.[0-9]+`) for public skill packages and research tools.
3. **Refspec Safety (CWE-20)**: Asserts that tag refnames do not contain path traversal (`..`), illegal control characters, or refspec injection vectors.
4. **Deterministic Testing**: Includes comprehensive unit tests in `tasks/test_check_git_tag_signatures.py` and registers check rows in `check-all.ps1`.
