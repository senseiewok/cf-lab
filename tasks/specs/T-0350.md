## 1. Curative Mission & Architecture Stewardship Scope

Implements `tasks/check_git_remote_invariants.py` to audit git configuration, remote tracking URLs, and transport protocol safety across all workspace repositories (cf-lab, cf-research, cf-skills, .ai):
1. **Remote URL Protocol Whitelist**: Strictly enforces that all repository git remotes use secure HTTPS (`https://github.com/...`) or SSH (`git@github.com:...`) protocols, prohibiting insecure plaintext HTTP or unauthenticated git:// protocols.
2. **Credential Embedding in Git Remotes**: Prohibits any embedded username/password or token in remote URLs (e.g. `https://token@github.com/...`), enforcing credential helper or environment token authentication.
3. **Official Upstream Namespace Alignment**: Verifies that remotes point to the designated official organizational namespace (`senseiewok/*`), preventing remote hijacking or accidental sync to unauthorized forks.
4. **Deterministic Testing**: Includes comprehensive unit tests in `tasks/test_check_git_remote_invariants.py` and registers check rows in `check-all.ps1`.
