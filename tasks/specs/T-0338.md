## 1. Curative Mission & Architecture Stewardship Scope

Implements `tasks/check_github_workflow_permissions.py` to audit GitHub Actions workflow definitions across all workspace repositories (.github/workflows/*.yml):
1. **Explicit Top-Level Permissions Block**: Verifies that every workflow file declares an explicit top-level `permissions:` block, prohibiting reliance on default permissive repository tokens.
2. **Least Privilege Enforcement**: Ensures workflows only request the minimal required scopes (`contents: read`, `pull-requests: write`, etc.), strictly flagging unnecessary `write-all` or unconstrained permissions.
3. **Third-Party Action Pinning by Full SHA**: Audits `uses:` directives across all workflows to ensure third-party GitHub Actions are pinned to full immutable 40-character commit SHAs rather than mutable branch or tag names (e.g. `@main`, `@v1`).
4. **Deterministic Testing**: Includes comprehensive unit tests in `tasks/test_check_github_workflow_permissions.py` and registers check rows in `check-all.ps1`.
