## 1. Curative Mission & Architecture Stewardship Scope

Implements `tasks/check_path_traversal.py` to audit file path handling, canonical path resolution, and directory containment across all workspace repositories (cf-lab, cf-research, cf-skills, .ai):
1. **Directory Traversal Invariants**: Detects raw string concatenation with path separators and unvalidated `os.path.join()` or `Path()` calls using unsanitized user or external input that could allow `../` traversal outside designated workspace bounds (CWE-22).
2. **Canonical Path Resolution**: Enforces the use of `.resolve()` or `os.path.realpath()` combined with strict `is_relative_to()` or commonpath boundary assertions before file system access.
3. **Symlink Escaping Invariants**: Flags file read and write operations that fail to verify whether target symlinks resolve outside the repository tree (CWE-59).
4. **Deterministic Testing**: Includes comprehensive unit tests in `tasks/test_check_path_traversal.py` and registers check rows in `check-all.ps1`.
