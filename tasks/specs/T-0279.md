## 1. Operational Security & PR Pipeline Automation

Automates remediation of the GitHub PR repair queue identified in `tasks/audit_github_hygiene.py`:
1. Safely detects superseded sentinel PRs whose referenced board tasks are already marked done on `origin/main`, confirms identical tree deliverables, and closes the duplicate PR with an explanatory comment.
2. Identifies branch/title task-ID discrepancies (such as research tools cited in showcase PR titles) and normalizes them to prevent false positive superseded warnings.
3. Emits structured JSON alerts for manual intervention when unresolvable merge conflicts or review blockers are detected.

## 2. Primary Source Grounding

1. **tasks/audit_github_hygiene.py**: `audit_prs()` and `pr_issues()` logic across all workspace repositories.
2. **tasks/pick_bold_task.py**: PR repair gating preventing sentinel starvation.
3. **AGENTS.md**: Automated review loop, PR gate integrity, and zero-token idle requirements.
