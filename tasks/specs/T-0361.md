## 1. Curative Mission & Architecture Stewardship Scope

Implements `tasks/check_env_canary_leakage.py` to audit environment variable inheritance, subprocess execution environments, and secret canary token isolation across all workspace repositories (cf-lab, cf-research, cf-skills, .ai):
1. **Subprocess Environment Isolation (CWE-200)**: Audits all `subprocess.run()`, `subprocess.Popen()`, and shell invocation patterns to ensure child worker processes do not unconditionally inherit parent process environment variables containing API credentials or sensitive tokens.
2. **Canary Token Isolation**: Verifies that synthetic canary values defined in security test suites or `.env.example` are strictly quarantined and never logged, outputted in public artifacts, or committed to git tracking.
3. **Deterministic Sanitization Primitives**: Provides a safe execution environment constructor `get_isolated_agent_env()` that strips unwhitelisted environment variables before launching untrusted model or tool commands.
4. **Deterministic Testing**: Includes comprehensive unit tests in `tasks/test_check_env_canary_leakage.py` and registers check rows in `check-all.ps1`.
