## 1. Curative Mission & Architecture Stewardship Scope

Implements `tasks/check_git_supply_chain_integrity.py` to audit external dependencies, git submodule pointers, package configurations, and remote URL imports across the multi-repo workspace:
1. **Submodule Pinning & SHA-1/SHA-256 Validation**: Asserts that git submodules (if configured in `.gitmodules`) point strictly to pinned commit SHAs rather than moving branch heads, with verified HTTPS remote URLs.
2. **Third-Party Skill & Dependency Quarantine**: Verifies that third-party skill folders listed in `THIRD_PARTY_SKILLS.md` match explicit gitignore exclusions and never leak unreviewed upstream dependencies into public git trees.
3. **External CDN & Dynamic Import Guard**: Scans HTML and JS files in web roots for unpinned or dynamic external script tags (`<script src="https://...">`), enforcing strict CSP and zero-CDN buildless architecture.
4. **Deterministic Testing**: Includes unit test suite in `tasks/test_check_git_supply_chain_integrity.py` and registers check rows in `check-all.ps1`.
