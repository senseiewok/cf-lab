## 1. Operational Reliability & Security Objective

Addresses the 4 actionable failure patterns mined across 43 recent agent sessions in `.loop-logs/session-error-digest.json` (`tasks/audit_session_errors.py`). Delivers a deterministic static analysis tool (`tasks/check_agent_command_safety.py`) and unit tests (`tasks/test_check_agent_command_safety.py`) that verify:
1. Agent command invocations, sentinel runner scripts, and markdown skills do not embed unescaped nested double quotes in `python -c "..."` or `pwsh -Command "..."` strings which frequently trigger PowerShell `ParserError` and non-zero exit codes.
2. Cross-repository tool references dynamically resolve sibling workspace paths using standard anchors (`check-workspace.py` or `Path(__file__).resolve().parent`) rather than assuming hardcoded working directory layouts.
3. Sentinel sidecar prompt files adhere to non-interactive command flags and explicit timeout constraints.

## 2. Primary Source Grounding

1. **tasks/audit_session_errors.py** and **.loop-logs/session-error-digest.json** (Sensei Ewok CF Lab forensic session logs, 2026-10-21).
2. **AGENTS.md**: Single-command check rules, sibling workspace directory structure, and Windows PowerShell command compatibility.
3. **.claude/skills/windows-powershell-commands/SKILL.md**: Proper quoting and argument parsing rules for PowerShell cmdlets and Python sub-processes on Windows.
