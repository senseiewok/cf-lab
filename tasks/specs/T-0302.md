## 1. Curative Mission & Architecture Stewardship Scope

Implements `tasks/check_sentinel_telemetry_linter.py` to audit scheduled sentinel run telemetry, lock lifecycle records, and watermark states across `.loop-logs/`:
1. **Sentinel Heartbeat & Cadence Validation**: Inspects `tasks/sentinels.json` declarations against `.loop-logs/sentinel-runs.jsonl` to assert that runs adhere to configured cadences without execution drift.
2. **Git Commit Tree Watermark Verification**: Confirms that commit hashes referenced in `.loop-logs/last-showcase-audit.json`, `last-research-audit.json`, and `sentinel-runs.jsonl` resolve to real, existing commits in git reflogs.
3. **Lock Lifetime & Concurrency Drift Audit**: Verifies that lock acquisition records, timestamps, and process IDs never exceed maximum timeout budgets (4 hours) and flags abandoned lock remnants.
4. **Zero-Token Idle Invariant Compliance**: Audits that sentinels cleanly exit with code 10 (`LOCK_HELD`) or code 20 (`IDLE`) without burning API tokens when no tree deltas exist.
5. **Deterministic Testing**: Includes comprehensive unit tests in `tasks/test_check_sentinel_telemetry_linter.py` and registers check rows in `check-all.ps1`.
