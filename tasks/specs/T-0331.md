## 1. Curative Mission & Architecture Stewardship Scope

Implements `tasks/check_ast_obfuscation_invariants.py` to audit Python source files across all workspace repositories for dangerous dynamic code execution and import obfuscation patterns:
1. **Dynamic Execution Primitives**: Scans ASTs for prohibited execution built-ins: `exec()`, `eval()`, `compile()`, and dynamic string invocation through `__import__()`.
2. **Obfuscated Payload Detection**: Identifies base64 payload unpacking (e.g. `base64.b64decode()`), zlib/gzip decompression chains fed into interpreters, and hex/unicode escape-obfuscated byte strings.
3. **Reflection & Sandbox Escape Guards**: Detects dangerous reflection idioms accessing internal Python state (`sys.modules`, `__subclasses__()`, `__globals__`, `__builtins__`).
4. **Deterministic Testing**: Includes comprehensive unit tests in `tasks/test_check_ast_obfuscation_invariants.py` and registers check rows in `check-all.ps1`.
