## 1. Curative Mission & Architecture Stewardship Scope

Implements `tasks/check_dynamic_imports.py` to audit dynamic module loading, `__import__()`, `importlib.import_module()`, and `exec()/eval()` module instantiation patterns across all workspace repositories (cf-lab, cf-research, cf-skills, .ai):
1. **Dynamic Import Sandboxing (CWE-829 / CWE-470)**: Audits all calls to `importlib.import_module()` and `__import__()` to ensure module names originate from static literals or explicitly whitelisted lab module registries, preventing arbitrary code execution via untrusted module path injection.
2. **Dynamic Exec/Eval Import Elimination**: Strictly flags `eval()` or `exec()` invocations containing import statements in runtime scripts.
3. **Safe Dynamic Import Primitives**: Provides `safe_import_module(module_name: str, allowed_modules: Set[str])` that verifies module namespace containment before invoking Python import internals.
4. **Deterministic Testing**: Includes comprehensive unit tests in `tasks/test_check_dynamic_imports.py` and registers check rows in `check-all.ps1`.
