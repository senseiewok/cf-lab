## 1. Curative Mission & Architecture Stewardship Scope

Implements `tasks/check_git_branch_conventions.py` to audit git branch names, active worktree references, and remote tracking refs across all workspace repositories (cf-lab, cf-research, cf-skills, .ai):
1. **Semantic Branch Naming Conventions**: Asserts that all local and remote branches conform to strict lab taxonomy: `feat/*`, `fix/*`, `work/*`, `site/*`, `docs/*`, `chore/*`, `ci/*`, or `skills/*`, preventing rogue or untracked branch sprawl.
2. **Task ID & Topic Association**: Verifies that work branches incorporate valid task IDs (`T-XXXX`) or well-formed kebab-case topic slugs, facilitating automated PR linking and board synchronization.
3. **Character Set & Path Traversal Safety**: Prohibits problematic characters (whitespace, colons, backslashes, control characters, or trailing slashes) that cause cross-platform refspec collision or script injection (CWE-20).
4. **Deterministic Testing**: Includes comprehensive unit tests in `tasks/test_check_git_branch_conventions.py` and registers check rows in `check-all.ps1`.
