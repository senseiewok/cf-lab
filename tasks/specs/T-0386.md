## 1. Curative Mission & Architecture Stewardship Scope

Implements `tasks/check_git_remote_refspecs.py` to audit git remote configurations and refspec patterns across all workspace repositories (cf-lab, cf-research, cf-skills, .ai):
1. **Remote URL Whitelist & Protocol Verification (CWE-284)**: Enforces that all configured git remotes strictly adhere to authorized GitHub repository endpoints under `https://github.com/senseiewok/` or `git@github.com:senseiewok/`, prohibiting unauthorized third-party git remotes or untrusted mirror targets.
2. **Wildcard & Destructive Push Refspec Elimination**: Prohibits dangerous push refspecs (e.g. `+refs/heads/*:refs/heads/*` or unconstrained wildcard matching) that could inadvertently overwrite remote branches during agent pushes.
3. **Embedded Credential Detection (CWE-522)**: Verifies that remote URLs do not contain plaintext personal access tokens (PATs), usernames, or passwords.
4. **Deterministic Testing**: Includes comprehensive unit tests in `tasks/test_check_git_remote_refspecs.py` and registers check rows in `check-all.ps1`.
