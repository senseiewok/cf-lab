## 1. Curative Mission & Architecture Stewardship Scope

Implements `tasks/check_file_permission_invariants.py` to audit git file mode bits (`100644` vs `100755`) and filesystem permissions across all workspace repositories:
1. **Strict Non-Executable Data File Invariant**: Asserts that static assets, documentation, and configuration files (`.json`, `.md`, `.yaml`, `.yml`, `.txt`, `.html`, `.css`, `.png`, `.svg`) are strictly non-executable (`100644`) in the git index across all repositories.
2. **Script Shebang & Executable Bit Parity**: Verifies that shell scripts (`.sh`) and standalone CLI scripts (`.py` with `#!/usr/bin/env ...`) maintain correct executable permissions without accidental bit flips during cross-platform Windows/Linux checkouts.
3. **Automated Git Index Mode Verification**: Uses `git ls-files -s` to inspect the git object tree directly, catching accidental chmod permission drift before commits are published.
4. **Deterministic Testing**: Includes unit test suite in `tasks/test_check_file_permission_invariants.py` and registers check rows in `check-all.ps1`.
