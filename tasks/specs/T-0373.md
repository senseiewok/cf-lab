## 1. Curative Mission & Architecture Stewardship Scope

Implements `tasks/check_concurrency_deadlocks.py` to audit asynchronous and multi-threaded agent tooling across all workspace repositories (cf-lab, cf-research, cf-skills, .ai) to prevent thread deadlocks and event loop lockup:
1. **Event Loop Nesting & Blocking (CWE-833)**: Audits calls to `asyncio.run()`, `get_event_loop().run_until_complete()`, and blocking synchronization primitives within async coroutines to eliminate nested event loop crashes.
2. **Lock Acquisition Timeout Invariants**: Enforces that all thread synchronization primitives (`threading.Lock`, `threading.RLock`, `asyncio.Lock`) incorporate bounded timeout or deadlock-safe context managers in production daemons.
3. **Unbounded Future Wait Detection**: Flags unbounded `asyncio.wait()`, `asyncio.gather()`, or thread `.join()` calls lacking explicit timeout envelopes.
4. **Deterministic Testing**: Includes comprehensive unit tests in `tasks/test_check_concurrency_deadlocks.py` and registers check rows in `check-all.ps1`.
