## 1. Security Architecture & Agent Invariant Scope

Implements `tasks/check_subprocess_injection_guard.py` to audit Python scripts across all four workspace repositories (`cf-lab`, `cf-research`, `cf-skills`, `.ai`) that execute `subprocess.run`, `subprocess.Popen`, `os.system`, or related process execution APIs. Enforces strict zero-vulnerability invariants:
1. Prohibits `shell=True` when executing commands with variable or external parameters.
2. Enforces list-based argument arrays for all process invocations.
3. Requires strict regex validation (such as `^[A-Za-z0-9_\-\./]+$`) on all dynamic parameters (branch names, PR numbers, file paths, repository slugs) to prevent argument injection (CWE-88) and command injection (CWE-78).
4. Verifies mandatory finite execution timeouts across all subprocess calls to prevent denial-of-service hanging.
5. Verifies integration of `redact_sensitive` sanitizers to protect API tokens and personal emails from leaking into logs or exception traces.
