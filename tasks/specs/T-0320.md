## 1. Curative Mission & Architecture Stewardship Scope

Implements `tasks/check_unicode_homoglyphs.py` to audit source code, configuration files, and data catalogs across all workspace repositories for deceptive Unicode injections:
1. **Trojan Source (CVE-2021-42574) Detection**: Detects bidirectional control characters (Bidi: U+202A..U+202E, U+2066..U+2069) that alter visual code ordering without changing execution semantics.
2. **Invisible & Zero-Width Character Quarantine**: Scans for zero-width spaces (U+200B), zero-width non-joiners (U+200C), zero-width joiners (U+200D), and soft hyphens (U+00AD) in python/powershell scripts, markdown documentation, and JSON catalogs.
3. **Confusable Homoglyph Auditing**: Flags Cyrillic/Greek homoglyphs substituting Latin ASCII identifiers in function, class, or variable declarations.
4. **Deterministic Testing**: Includes unit test suite in `tasks/test_check_unicode_homoglyphs.py` and registers check rows in `check-all.ps1`.
