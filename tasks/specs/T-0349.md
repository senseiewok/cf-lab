## 1. Curative Mission & Architecture Stewardship Scope

Implements `tasks/check_tempfile_security.py` to audit temporary file creation, directory permissions, and cleanup lifecycle patterns across all workspace repositories (cf-lab, cf-research, cf-skills, .ai):
1. **Insecure Tempfile & Predictable Path Invariants**: Prohibits hardcoded paths under `/tmp`, `C:\Windows\Temp`, or predictable static file names, requiring standard `tempfile.TemporaryDirectory()`, `tempfile.NamedTemporaryFile()`, or context-managed scratch paths.
2. **Restrictive Mode Bits on Temp Directories**: Verifies that temporary files and folders are created with restrictive permissions (e.g. `0o700` / `0o600`), preventing local symlink hijacking and insecure multi-user shared access (CWE-377 / CWE-379).
3. **Deterministic Cleanup & Context Lifecycle**: Audits Python AST and PowerShell scripts to ensure all generated temporary files are cleaned up in `try...finally` blocks or context managers, preventing resource exhaustion and disk leaks.
4. **Deterministic Testing**: Includes comprehensive unit tests in `tasks/test_check_tempfile_security.py` and registers check rows in `check-all.ps1`.

## 2. Primary Source Grounding

- OWASP Secure Coding Practices: Section 13 (File System Operations)
- CWE-377: Insecure Temporary File / CWE-379: Creation of Temporary File in Directory with Incorrect Permissions
- Workspace Standards: `.claude/skills/security-baseline/SKILL.md`, `.claude/skills/security-runtime/SKILL.md`
