## 1. Curative Mission & Architecture Stewardship Scope

Implements `tasks/check_playwright_test_hygiene.py` to audit Playwright visual regression test infrastructure and artifact storage across the workspace:
1. **Orphaned Background Server Detection**: Scans for dangling local HTTP server processes (ports 8000, 8080, 8888) spawned during visual test runs and provides safe, deterministic teardown verification.
2. **Artifact Quarantine & Gitignore Invariant**: Asserts that browser traces, video recordings, and screenshot artifacts under `../cf-lab-files/scratch/screenshots/` and `.playwright/` are strictly excluded from git tracking.
3. **Browser Binary Provenance**: Verifies that Playwright setup scripts strictly point to isolated external browser caches outside git repositories, preventing large binary bloat.
4. **Deterministic Testing**: Includes unit test suite in `tasks/test_check_playwright_test_hygiene.py` and registers check rows in `check-all.ps1`.
