## 1. Operational Security & Script Quoting Safety

Statically inspects agent session commands, tasks scripts, and skill definitions across workspace repositories to catch quoting traps, parser failures, and brittle traversal patterns before execution:
1. Catches unescaped nested double quotes in inline Python and PowerShell commands (e.g. `python -c "import foo; bar = "baz""` or `pwsh -Command "..."`).
2. Detects hardcoded machine or user home directory paths (such as user profile directories) to prevent environment-specific execution breakage.
3. Flags fragile deep relative directory traversal (`../../../`) without root workspace anchors.
