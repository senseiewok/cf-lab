## 1. Curative Mission & Architecture Stewardship Scope

Implements `tasks/check_markdown_link_integrity.py` to audit documentation, task specifications, skills, and architectural designs across Sensei Ewok's CF Lab repositories:
1. Enforces that all local relative markdown file links (`[label](path/to/file)`) resolve to real files on disk.
2. Validates same-file and cross-file anchor fragments (`[label](path/to/file#anchor)` or `[label](#anchor)`) against GitHub-flavored markdown heading slugs and explicit HTML anchor IDs (`<a name="...">` / `<a id="...">`).
3. Safely ignores external URLs (`http://`, `https://`), mailto links, file URIs, custom IDE schemes (`sidecar://`, `conversation://`), and template placeholders (`<...>`).
4. Accommodates duplicate heading slugs (`slug`, `slug-1`, `slug-2`) and collapsed-hyphen normalization.
5. Provides deterministic `--check` and `--json` CLI interfaces returning exit 0 on clean runs and exit 1 on detected broken links.
6. Includes comprehensive unit test suite `tasks/test_check_markdown_link_integrity.py` and registers check rows in `check-all.ps1`.
