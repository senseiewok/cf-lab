## 1. Curative Mission & Architecture Stewardship Scope

Implements `tasks/check_tool_permission_invariants.py` to audit agent permission configurations across `.claude/settings.json`, `.claude/settings.local.json.example`, and `.github/copilot-instructions.md`:
1. **Critical Tool Command Denial Verification**: Audits that high-risk shell patterns (e.g. `rm -rf`, raw GitHub administrative mutations, unchecked external network scripts) are explicitly denied in all session startup configurations.
2. **Read-Only Reviewer Scope Enforcement**: Verifies that read-only reviewer agent profiles cannot execute file write tools or arbitrary shell commands.
3. **Workspace Path Containment**: Confirms that permitted directory paths in `permissions.additionalDirectories` strictly resolve to sibling workspace roots (`cf-research`, `cf-skills`, `.ai`) and never to parent user folders.
4. **Denial Rule Symmetry**: Asserts that secret file deny rules (`Read(.env)`, `Read(.*secret*)`, `Read(.*id_rsa*)`) are mirrored consistently across all repository configurations.
5. **Deterministic Testing**: Includes unit test suite in `tasks/test_check_tool_permission_invariants.py` and registers check rows in `check-all.ps1`.
