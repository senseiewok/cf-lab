## 1. Curative Mission & Architecture Stewardship Scope

Implements `tasks/check_async_task_leaks.py` to audit asynchronous background tasks, unawaited futures, and worker thread lifecycle management across all workspace repositories (cf-lab, cf-research, cf-skills, .ai):
1. **Unawaited Coroutine Task Leaks (CWE-404 / CWE-772)**: Audits `asyncio.create_task()` and `loop.create_task()` calls to ensure generated tasks are retained in tracked collections or explicitly shielded/cancelled during daemon shutdown to prevent zombie task accumulation.
2. **Non-Daemon Worker Thread Elimination**: Enforces `daemon=True` on all `threading.Thread` instances created by agent background tools to guarantee clean termination on process exit.
3. **Fire-and-Forget Exception Suppression**: Audits background coroutines to ensure task completion callbacks (`task.add_done_callback()`) or try/except handlers trap exceptions and prevent silent event loop crashes.
4. **Deterministic Testing**: Includes comprehensive unit tests in `tasks/test_check_async_task_leaks.py` and registers check rows in `check-all.ps1`.
