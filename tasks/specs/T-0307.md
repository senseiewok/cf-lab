## 1. Curative Mission & Architecture Stewardship Scope

Implements `tasks/check_env_canary_isolation.py` to audit environment variable configuration files (`.env`, `.env.example`, `.env.test`) across all workspace repositories:
1. **Zero-Leakage Canary Verification**: Asserts that git-tracked test canary tokens (e.g. `OPENALEX_API_KEY_CANARY`, mock API keys) never collide with real keys in private `.env`.
2. **Entropy & Key Structure Auditing**: Validates that keys defined in untracked `.env` conform to provider-specific length and character patterns without falling below baseline entropy requirements.
3. **Template Parity & Stale Variable Guard**: Ensures every required configuration slot in `.env.example` has corresponding documentation in `README.md` and `docs/SETUP.md`.
4. **File Permission & Gitignore Invariant**: Asserts that `.env` is rigorously ignored across `.gitignore` in `cf-lab`, `cf-research`, `cf-skills`, and `.ai`.
5. **Deterministic Testing**: Includes unit test suite in `tasks/test_check_env_canary_isolation.py` and registers check rows in `check-all.ps1`.
