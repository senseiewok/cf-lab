## 1. Curative Mission & Architecture Stewardship Scope

Implements `tasks/check_git_commit_signatures.py` to audit git commit metadata, commit signing configuration, and author identity consistency across all workspace repositories (cf-lab, cf-research, cf-skills, .ai):
1. **Commit Signature Verification**: Audits git history and branch tips for valid cryptographic GPG or SSH signatures (`git log --show-signature`), verifying non-repudiation and preventing forged commits in PR workflows.
2. **Author Identity & Email Whitelist**: Verifies that commit authors and committers match authorized organization identities (`diego@senseiewok.ai`, `senseiewok-dev`), prohibiting unverified identity spoofing (CWE-287).
3. **Local Commit Signing Configuration**: Audits local and repository `.git/config` for `commit.gpgsign = true` or `gpg.format = ssh` compliance, providing automated warnings when local signing is disabled.
4. **Deterministic Testing**: Includes comprehensive unit tests in `tasks/test_check_git_commit_signatures.py` and registers check rows in `check-all.ps1`.
