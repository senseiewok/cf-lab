# T-0222: Interactive Base Editing (ABE8e) Protospacer Window & Bystander Edit Simulator Panel

## 1. Overview & Curative Mission Focus (Track B)
To translate biophysical advances in base editing for premature termination codons (PTCs) into public, accessible clinical understanding, this specification directs the creation of an interactive client-side simulator on `senseiewok.ai` under `/cf/ptc/` and `/cf/cftr/`. Patients, families, and researchers can select refractory alleles (`W1282X`, `R553X`, `G542X`, `2789+5G->A`), toggle editor architectures (`ABE8e`, `ABE7.10`, `SpCas9-NG`, `SpRY`), visualize the deamination efficiency window across the 20-nt protospacer, and inspect predicted bystander missense outcomes with Mexican Spanish (`es-MX`) parity.

## 2. Primary Evidence Grounding
- **Editor Activity & Bystander Metrics**: Richter et al., *Nature Biotechnology*, 2020. DOI: `10.1038/s41587-020-0453-z`.
- **Investigational Clinical Trial**: Clinical evaluation of base/prime editing delivery in genetic respiratory disease. ClinicalTrials.gov ID: `NCT06237335`.
- **Mutation Registry Grounding**: CFTR2 clinical database and ClinVar classifications for nonsense mutations.

## 3. Architecture & User Interface Design
- **DOM Components & IDs**:
  - Container: `<section id="ptc-simulator" class="tool-section" aria-labelledby="ptc-sim-heading">`
  - Selector: `<select id="ptc-target-select" aria-label="Select Target CFTR Mutation">` with options for `W1282X`, `R553X`, `G542X`, and `2789+5G->A`.
  - Editor Toggle: `<div id="ptc-editor-toggles" role="radiogroup" aria-label="Base Editor Enzyme">` with options `ABE8e (Broad Window 3-9)` and `ABE7.10 (Narrow Window 4-8)`.
  - Visualizer: `<svg id="ptc-protospacer-window-svg" viewBox="0 0 800 240" role="img" aria-label="Protospacer deamination window diagram">`
    - Displays 20 nucleotides with position markers 1 to 20, the $NGG$/PAM motif in green/gold, and target adenine highlighted.
    - Overlay Gaussian curve showing deamination probability $W(p) = \exp(-(p - p_0)^2 / (2\sigma^2))$.
    - Animation pause button: `<button type="button" class="svg-motion-toggle" data-svg-target="ptc-protospacer-window-svg" aria-pressed="false">Pause</button>`
  - Bystander Analysis Table: `<div id="ptc-bystander-table" class="data-table-container">` displaying position, bystander nucleotide, predicted amino acid change, and Cryo-EM structural tolerance classification.
- **Zero-Build & CSS Standards**:
  - Pure ES module architecture: `src/scripts/ptc-simulator.js` with zero bundlers, using standard EventTarget Pub/Sub.
  - Responsive layout: Mobile 375px zero-overflow (`grid-template-columns: 1fr` below 640px, `min-width: 0` on flex/grid children).
  - Localization: 100% string coverage in Mexican Spanish (`es-MX.json`), with aria-labels translated.

## 4. Deliverables & Target Files
- In repository `.ai`:
  - `src/cf/ptc/index.html`: Base editing simulator panel markup, schema metadata, and accessible landmarks.
  - `src/scripts/ptc-simulator.js`: Pure ES module implementing target mutation sequence lookup, editing probability calculations, SVG window rendering, and bystander outcome tables.
  - `src/locales/es-MX.json`: Complete Spanish strings for all simulator labels, explanations, and safety caveats.
  - `tests/test_ptc_simulator.py`: Python unit tests verifying DOM IDs, markup semantics, and translation coverage.
