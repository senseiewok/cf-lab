## 1. Curative Mission & Architecture Scope

Implements `tasks/check_secret_entropy_linter.py` and unit tests in `tasks/test_check_secret_entropy_linter.py` to continuously enforce the lab's secret-free git invariant. Extends existing regex scanners with Shannon entropy analysis ($H > 4.5$) on strings of length $\ge 20$, scanning staged files, agent session transcripts, and uncommitted diffs for high-entropy tokens, private keys, and API secrets (GitHub `ghp_`/`gho_`, AWS access keys, Anthropic `sk-ant-`, OpenAI `sk-`, Google `AIza...`), with calibrated allowlists for Git commit SHAs, SVG paths, UUIDs, and base64 hashes.
