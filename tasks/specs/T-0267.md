# T-0267: Portable CFTR Variant Sequence Context & Splice/PAM Annotator in cf-evidence-loop (cf-skills)

## Engineering & Scientific Objective
Extend the public `cf-skills` repository (`.claude/skills/cf-evidence-loop/`) so that `evidence_cli.py brief variant` (and a new deterministic helper `scripts/cftr_Tier1_context.py`) can optionally attach verified RefSeq `NM_000492.4` / UniProt `P13569` exon number, domain location (TMD1, NBD1, R-domain, TMD2, NBD2), and canonical codon/splice context alongside ClinVar and OpenTargets API records—while strictly preserving non-clinical boundaries (never interpreting a person's genotype or recommending therapy).

Additionally, add a CI test in `cf-skills/tests/test_pin_catalog.py` that verifies `catalog.lock.json` schema integrity and ensures `scripts/pin_catalog.py --check` is executed as part of `scripts/check_repo.py` so any unpinned edit to `.claude/skills/cf-evidence-loop/catalog.yaml` is caught immediately by `check_repo.py`.

## Primary Sources & Grounding
- Catalog & Identifiers: `sources/catalog.yaml` (`clinvar`, `uniprot`, `ncbi_eutils`), `PDB:6MSM`, `PDB:8EIQ`, `ClinicalTrials.gov:NCT05248230`
- Existing Codebase (`cf-skills`):
  - `.claude/skills/cf-evidence-loop/scripts/evidence_cli.py`
  - `scripts/check_repo.py`
  - `scripts/pin_catalog.py`
  - `tests/test_pin_catalog.py`

## Deliverables & Acceptance Criteria
1. Integrate `pin_catalog.check()` into `cf-skills/scripts/check_repo.py` so `python scripts/check_repo.py` verifies `catalog.yaml` against `catalog.lock.json`.
2. Add structural domain & RefSeq exon lookup table (`P13569` / `NM_000492.4`) to `.claude/skills/cf-evidence-loop/` with explicit non-clinical scope boundaries and offline unit tests.
3. Verification command:
   ```bash
   python scripts/check_repo.py && python scripts/pin_catalog.py --check && python -m unittest discover tests
   ```
