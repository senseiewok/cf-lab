# T-0226: Deterministic SVG/WebGL2 ?t=SECONDS Visual Visibility & Mobile Zero-Overflow Verifier

## 1. Overview & Curative Mission Focus (Scientific Integrity / Quality)
Visualizing complex biophysical structures (CFTR cryo-EM electron density, AAV capsid delivery tropism, allosteric dose-response curves) on `senseiewok.ai` requires deterministic testability:
1. When animations are paused for automated visual review (`capture_site_review.py`) or under user reduced-motion preferences, dynamically drawn SVG paths styled with CSS line-dash animation (`stroke-dashoffset: 1`) risk becoming completely invisible if frozen before animation completion.
2. In WebGL2 canvases, shader execution must deterministically freeze time (`u_time`) via query parameter `?t=SECONDS` while gracefully recovering from context loss (`webglcontextlost`) and falling back to 2D context in headless environments.
3. On narrow mobile viewports (< 640px, down to 375px), slider controls and parameter grids must collapse to single-column layouts (`grid-template-columns: 1fr` with `min-width: 0`) to prevent horizontal clipping.

This specification directs the implementation of an automated verification test suite in `cf-lab` (`tasks/test_svg_freeze_contract.py`) ensuring strict compliance across all SVG and WebGL2 visual assets.

## 2. Primary Evidence Grounding
- **SVG Animation Standards**: `.claude/skills/svg-animation/SKILL.md` enforcing WCAG 2.2.2 motion controls, `.is-svg-frozen-time` CSS overrides (`stroke-dashoffset: 0 !important`), and universal `[data-svg-target]` pause buttons.
- **WebGL2 Design Pattern**: `.claude/skills/webgl-threejs-graphics/SKILL.md` specifying shader time parameterization (`u_time`), headless canvas fallback, and resource deallocation.
- **Modern Responsive Web Standards**: `.claude/skills/modern-web-standards/SKILL.md` specifying fluid container queries and 375px zero-overflow layout budgets.

## 3. Architecture & Verification Checks
The verifier scans all HTML and JS visual assets across `.ai` and verifies:
1. **SVG Frozen Contract**:
   - Every `<svg>` element with animated paths contains or is governed by `.is-svg-frozen-time` rules ensuring lines are fully rendered (`stroke-dashoffset: 0`) when frozen.
   - Every animated SVG has an associated WCAG 2.2.2 pause/resume button with `data-svg-target="<SVG_ID>"` or `aria-controls`.
2. **WebGL2 Context & Shader Parameters**:
   - WebGL2 canvas scripts inspect `URLSearchParams` for `t` and pass static uniform float `u_time`.
   - Event listeners for `webglcontextlost` and `webglcontextrestored` are attached.
   - Headless test fallback (`canvas.getContext('2d')`) is provided.
3. **Mobile Layout Budget**:
   - CSS rules for `.tool-section`, `.cards-grid`, and `.slider-group` contain `@media (max-width: 640px)` rules enforcing `grid-template-columns: 1fr` and `min-width: 0`.
