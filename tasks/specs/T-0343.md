## 1. Curative Mission & Architecture Stewardship Scope

Implements `tasks/check_shell_pipe_safety.py` to audit process spawning, shell commands, and piping constructs across all workspace repositories (cf-lab, cf-research, cf-skills, .ai):
1. **Unquoted File Descriptor Redirection**: Scans scripts and command templates for unquoted stdout/stderr redirection operators (`>`, `>>`, `2>&1`, `|`) that ingest untrusted variables.
2. **Raw Command Chaining Invariants**: Detects unsafe shell operator chaining (`;`, `&&`, `||`) combined with dynamic string formatting, prohibiting command injection vulnerabilities.
3. **PowerShell & Bash Execution Wrappers**: Enforces that external processes use explicit argument lists (`subprocess.run(["cmd", "arg"])`, `pwsh -File script.ps1`) rather than `shell=True` with concatenated strings.
4. **Deterministic Testing**: Includes comprehensive unit tests in `tasks/test_check_shell_pipe_safety.py` and registers check rows in `check-all.ps1`.
