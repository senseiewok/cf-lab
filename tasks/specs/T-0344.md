## 1. Curative Mission & Architecture Stewardship Scope

Implements `tasks/check_import_shadowing.py` to audit file naming conventions and module imports across all workspace repositories (cf-lab, cf-research, cf-skills, .ai):
1. **Standard Library Module Shadowing**: Prohibits any repository file or directory from matching Python standard library module names (`math.py`, `json.py`, `os.py`, `io.py`, `sys.py`, `random.py`, `re.py`, `hashlib.py`), preventing unintended local shadowing.
2. **Third-Party Dependency Masquerading**: Ensures local module names do not collide with declared third-party dependencies or workspace packages (`yaml`, `pytest`, `requests`, `playwright`).
3. **Circular Import & Import Ordering Invariants**: Enforces that internal imports follow clean absolute or relative packaging paths without ambiguous module resolution.
4. **Deterministic Testing**: Includes comprehensive unit tests in `tasks/test_check_import_shadowing.py` and registers check rows in `check-all.ps1`.
